# Hiroshima y Nagasaki

Proyecto web sobre los eventos históricos de Hiroshima y Nagasaki.

## Estructura del Proyecto

```
hirochima-nagasaki/
├── index.html       # Página principal
├── index.css        # Estilos CSS
├── script.js        # Código JavaScript
├── README.md        # Este archivo
└── .gitignore       # Configuración de Git
```

## Cómo usar

1. Abre `index.html` en tu navegador
2. Edita los archivos según necesites:
   - `index.html` - Estructura HTML
   - `index.css` - Estilos
   - `script.js` - Lógica JavaScript

## Subir a Git

```bash
# Inicializar repositorio (si no está hecho)
git init

# Agregar archivos
git add .

# Crear commit
git commit -m "Inicial: estructura base del proyecto"

# Agregar remoto (si tienes un repositorio remoto)
git remote add origin <URL_DEL_REPOSITORIO>

# Subir a rama principal
git push -u origin main
```

## Requisitos

- Navegador web moderno
